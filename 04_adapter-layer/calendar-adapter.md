# Calendar / Event Carrier Compatibility Specimen

**Lifecycle:** METABOLIZED_PRIMITIVE_STUB  
**Current eligibility as fixed time-sovereignty node:** false  
**Reclaim disposition:** CANDIDATE_AFTER_POINTER_AND_UNIQUE_EVIDENCE_CHECK

Calendar／event／schedule system 只是 temporal representation carrier，不取得事件 Identity、Truth 或 Authority。舊「時權節點／事件盤／公盤」固定 ontology 已退休。

## Retained primitives
- Event identity 與 carrier event 分離。
- 時間變更保留 revision、owner/attendee authority、evidence、return/change trace。
- Reminder、calendar entry、workflow event、sensor timestamp、simulation timestep 都可承載 temporal state，但不因工具或格式變成不同 ontology。
- Failure 只影響相關 temporal projection branch。

## Successor binding
`Stable Existence → Temporal State/Event → Authority/Constraint → Carrier Projection → Evidence/Change → Return/Reconciliation`

工具名稱、Calendar 類型與副檔名不建立永久分類。完整 predecessor 留 Git history；正常 Reader 不需讀本 specimen。
